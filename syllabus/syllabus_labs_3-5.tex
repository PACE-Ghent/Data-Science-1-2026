\section{Learning outcomes}

After these three sessions you can:

\begin{enumerate}[label=\textbf{LO\arabic*}, leftmargin=1.4cm]
  \item load a CSV file with \code{pandas} and describe its structure,
        data types and missing values;
  \item select and filter rows and columns with boolean conditions, and
        sort the result;
  \item derive new columns (age, speed, BMI) and convert text to numbers
        and dates;
  \item clean a dataset and justify each choice: inconsistent text
        labels, wrong units, missing values and duplicates;
  \item summarize data per group with \code{groupby} and \code{agg}, and
        combine tables with \code{merge} without double counting;
  \item reshape data between a long and a wide shape with \code{melt}
        and \code{pivot\_table};
  \item compute basic features of a time series: heart-rate zones,
        rolling averages and resampling;
  \item choose a chart type that fits the question, and recognise
        misleading charts, such as a truncated axis;
  \item make histograms, box plots, scatter plots and line charts with
        \code{plotly.express}, with colour, facets and size for extra
        dimensions;
  \item make charts interactive with marimo UI elements and combine them
        into a dashboard.
\end{enumerate}

\section{Prerequisites}

Labs 1 and 2 (\emph{Introduction to Python I and II}): variables and data
types, operators, \code{if}/\code{elif}/\code{else}, functions, string
methods, lists, dictionaries, loops, and reading a CSV file with the
\code{csv} module. Lab 2 ends by summarizing \code{athletes.csv} with
plain Python; in lab 3 you see how \code{pandas} does the same in a few
lines.

\section{Working method}

\begin{itemize}
  \item Each block starts with a short demo in the notebook, followed by
        exercises you solve in the notebook itself.
  \item Use the automatic checks as feedback, not as the goal: when a
        check turns green, make sure you can explain \emph{why} your code
        works.
  \item You do the lab 4 mini-case in pairs.
  \item Lab 3 ends with an exit ticket: one technique you will reuse and
        one thing that is still unclear. Bring the unclear points to the
        next session.
\end{itemize}

\section{Preparation per session}

\begin{itemize}
  \item Check before every session that you can open the notebook,
        locally or on marimo.app, and read the course text for the lab
        next to the notebook.
  \item Before lab 3: review lists, dictionaries and functions from
        lab 2.
  \item Before lab 4: make sure you can explain every step of the
        cleaning pipeline at the end of lab 3, because lab 4 starts from
        it.
  \item Before lab 5: review \code{groupby}, \code{merge} and the long
        shape from lab 4. Charts with plotly express start from data in
        the long shape.
\end{itemize}
